## 핵심 차별 (과목1과)
- ⚙️ **커널 소스**: task_struct 필드·CFS 런큐·futex 경로·ext4 저널을 코드로.
- 🛠 **제작·강제**: [labs/08_고급](../../labs/08_고급/README.md) — libbpf/CO-RE C, XDP 패킷 드롭(강제), uprobe/USDT, ring buffer.
- 🔵 **이해 트랙**: 모든 코드를 한 줄씩 읽고, 직접 수정·확장한다.

## 평가 (제안)
출석·퀴즈 15% · 심화 실습(제작) 35% · 중간(커널 내부) 20% · 기말 프로젝트 30%.

**제출·합격 기준**: 심화 실습은 직접 빌드·수정한 코드 + **실제 실행 캡처**를 제출(예: `labs/08_고급` libbpf `make` 빌드 산출물 실행, XDP ICMP 드롭 강제 화면). 기말 프로젝트는 **자기검증 하네스 포함**이 필수이며 [강의 인덱스 §3의 30점 루브릭](README.md#기말-프로젝트-채점-루브릭-30점)으로 채점. 제출 형식·재제출·질문 채널은 [강의 인덱스 §3](README.md#3-평가-상세) 참조.

### 기말 프로젝트 예시
파일 접근 감사기 / execsnoop 보안 강화판 / 시스템콜 지연 히스토그램 / 컨테이너 인지 추적기 / 간단한 XDP 로드밸런서.
**모든 기말 프로젝트는 자기검증 하네스(의도 ↔ 관측 비교)를 포함**한다.
