# eBPF 입문 — 학부 강의자료 (한 학기 과정)

> **과목 한 줄 소개**: 리눅스 커널 안에서 안전하게 실행되는 프로그램 기술인 **eBPF** 를,
> 개념의 밑바닥(커널·시스템콜)부터 실제 추적 도구 제작·네트워킹·보안·관측성 응용까지
> 한 학기(15주) 동안 *직접 만들어 보며* 배우는 과목.

### 학습 성과 (Course Learning Outcomes)

이 과목을 마치면 학생은 다음을 할 수 있다.

1. 커널/사용자 공간·시스템콜의 동작을 설명하고, **왜 eBPF 가 필요한지** 정당화한다.
2. eBPF 의 **아키텍처**(바이트코드·검증기·JIT·맵·헬퍼)와 **프로그램 타입·부착 지점**을 구분한다.
3. **bpftrace / BCC / libbpf** 로 직접 추적기를 작성·로드·디버깅한다.
4. 시스템콜·네트워크 이벤트를 **프로세스(PID)별로 추적**하고, 결과의 정확성을 **스스로 검증**한다.
5. eBPF 의 **네트워킹·보안·관측성** 생태계(Cilium·Falco·Tetragon 등)를 이해하고 비교한다.
6. eBPF 의 **안전성 보장과 한계**를 비판적으로 평가한다.

## 3. 평가 상세

| 평가 | 비중 | 설명 |
|:---|:---:|:---|
| 출석·퀴즈 | 20% | 매주 자가점검 퀴즈 + 수업 참여 |
| 실습 과제 | 30% | 주차별 실습(7·8·9·10·11주가 핵심). 본 저장소 랩에서 수행 |
| 중간시험 | 20% | 1·2부 개념(아키텍처·프로그램 타입·검증기) 필기 |
| 기말 프로젝트 | 30% | eBPF 추적기를 **직접 설계·구현·검증**. 아래 예시 참고 |

### 기말 프로젝트 예시 주제

- 파일 접근 감사기: 어떤 프로세스가 어떤 경로를 여는지(openat) 추적 + 화이트리스트 위반 경보
- 프로세스 실행 감시기(execsnoop 류): 모든 새 프로세스 생성과 인자(argv) 기록
- DNS/HTTP 요청 추적기: uprobe 또는 소켓 필터로 애플리케이션 레벨 가시성
- 시스템콜 지연 히스토그램: 시스템콜별 소요시간 분포(`bpf_ktime`)로 성능 분석
- 컨테이너 인지 추적기: cgroup ID 로 컨테이너별 활동 구분

> 모든 기말 프로젝트는 본 랩의 두 실습처럼 **자기검증 하네스(의도한 동작 ↔ 관측 결과 비교)** 를 포함해야 한다.
