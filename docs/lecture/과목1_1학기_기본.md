## 학습 흐름
"eBPF 도구를 돌리는 실습"을 따라가다 보면 프로세스·스케줄링·메모리·동기화·파일·네트워크가 손에 잡힌다.
각 주차는 정규 주차 문서 + OS 모듈 + 실습 코드(examples/labs/projects)를 함께 쓴다.
